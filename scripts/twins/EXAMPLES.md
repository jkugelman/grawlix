# Twins examples

John's collected pairs and the groups they fall into; [`cases.tsv`](cases.tsv) holds them in the harness's form.

## Patterns

Rough groups; many pairs sit in two.

1. **Respaced, letters nearly the same.**
   The largest group: the word breaks move and at most a letter or two changes.
   THERE'S A WAY / THERESA MAY, SEETHING / SEE THINGS, VENTILATE / VENTI LATTE, SHIITAKES / SHIT TAKES, FLUSH OUT / FLU SHOT, CHIPPENDALE / CHIP AND DALE, PRESENTER / PRESS ENTER, AT ONE GO / ANTON EGO, ATHEIST / ART HEIST, SYNTAX / SIN TAX, ALL TIMER / ALTIMETER, CRISTOBAL / CRYSTAL BALL, PANCREASES / PAY INCREASES, ARAMEAN / AREA MAN, TECHNO / HECK NO, SCARECROW / SACRED COW, QANTAS / Q AND AS, BALL ARENA / BALLERINA.
2. **One chunk inserted or deleted.**
   One contiguous edit in an otherwise identical string, sometimes long.
   WABISABI / WASABI, INDIGO / INDIEGOGO, ALLELE / ALLELUIA, ACADEMIA / MACADAMIA, SHOGUN / SHOTGUN, FASCIATION / FASCINATION, CANNIBAL / CANNONBALL, DECADE / DECADENT, BABEL / BABYBEL, MARIE ANTOINETTE / MARIONETTE, AMELIA EARHART / AMELIORATE, SLY STONE / SLY STALLONE, HYPHENATION / HYPE NATION.
3. **One letter changed.**
   PILATES / PIRATES, CRACKPOT / CROCKPOT, ELECTRON / ELECTION, DECADENT / DECEDENT, DJINN / DJING, GOLF BALL / GOOFBALL, MINOTAUR / MINI TOUR, THERE'S A WAY / THERESA MAY.
4. **Same frame, consonants swapped.**
   The vowel pattern and rhythm hold while a consonant or two change, often at word starts.
   GRACE KELLY / GRAPE JELLY, KENT STATE / TENT STAKE, SERPENTINE / TURPENTINE, SARCASM / EARGASM, HALL OF FAMER / MALL OF AMERICA, GERONIMO / TETRONIMO, HYPHENATION / HIBERNATION, and the shared-skeleton families PAC-MAN / PIKMIN / POKEMON and MACARENA / MACARONI / MARCONI / MACRON.
5. **Letters moved or rearranged.**
   A letter or chunk jumps elsewhere, up to near-anagrams.
   BASS TRACKS / BRASS TACKS, BULL MARKET / BULLET MARK, FRENCH PRESS / FRESH PRINCE, SCRANTON / SCANTRON, ELECTRIC / ECLECTIC, ARMATURE / AMATEUR, CONICAL / LACONIC, JAMAICA / JICAMA, LEGATO / GELATO / EL GATO, TOVE LO / LOVE TO, SIMU LIU / LIMU EMU, FIRE TRUCK / FRIAR TUCK, HAMBURGERS / AMBERGRIS, GAY MARRY / GAMMA RAY, and the whole-word swap WILL FERRELL / PHARRELL WILLIAMS.
6. **Sound-alikes spelled differently.**
   Spelling distance is large but pronunciation is close.
   AESOP ROCK / ASAP ROCKY, BONSAI / BANZAI, ROUTE KANAL / ROOT CANAL, HARRY CAREY / HARAKARI, HIPPOCRATES / HYPOCRITES, VAS DEFERENS / VAST DIFFERENCE, MAI TAI / MUAY THAI, TOWER DEFENSE / TOUR DE FRANCE, AUTOBAHN / AUDUBON, AFFOGATO / AVOCADO, JACUZZI / J'ACCUSE, CHAPPELL ROAN / CHAPERONE, HEARSAY / HERESY, ADAM CHASE / EDAM CHEESE, MINNIE MOUSE / MINI MOUSSE, FORTRAN / 4CHAN, TYSM / 'TISM, TRES BIEN / TRANSBIAN, BICURIOUS / VICARIOUS.
7. **Rhymes and multirhymes.**
   Every syllable rhymes, or nearly, while the consonants around the vowels change.
   CAREER FAIR / TAHRIR SQUARE, CRAZY TRAIN / DAISY CHAIN, KIM STANLEY ROBINSON / SWISS FAMILY ROBINSON, COCOTAXI / CATAPLEXY, LULAMOON / BLUE LAGOON, FLOWER BED / SHOWER HEAD, PEAT MOSS / MEAT SAUCE, CHERRY TREE / DAIRY FREE / MARRY ME, LEMON TREE / CLEMENCY / YEMENI, SPRUCE TREE / BLUE SEA / BREWSKI / LOOSE TEA, LIMA BEAN / TIME MACHINE.
8. **A long, unusual run shared.**
   A single word opens or closes with an unlikely string of letters that a phrase spells across a word break, and the rare string in common outweighs ends that differ.
   PSILOCYBIN / PS I LOVE YOU, ULCERATE / UL CERTIFIED, ATMOSPHERE / AT MOST, JESUIT / JE SUIS CHARLIE, AMIGOS / AM I GOOD, IAMBIC / I AM BIG IT'S THE PICTURES THAT GOT SMALL, ATLASES / AT LAST, ASBESTOS / AS BEST AS ONE CAN, ALGORISM / AL GORE, ATROCIOUS / AT ROCK BOTTOM, NYSTAGMUS / NY STATE, CHIMPANZEE / TAPPAN ZEE.
9. **One sound moved.**
   Read aloud, the pair differs by one phone moved elsewhere or two neighbors swapped, however different the spellings.
   FIRE TRUCK / FRIAR TUCK, TREE SURGEON / RESURGENT, KOREAN AIR / CORONARY, CAT CHOW / CATCH OUT, HYDRO / HIGH ROAD, FAULT ZONE / FALL TONES, COME FIRST / COMFORTS, DEER FLY / DEAR LIFE, QUINCE TREE / WIN STREAK, CATTLE DOG / CATALOGUED.
